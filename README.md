# 脑腐海湾 Brainrot Bay · 中文版

**在线试玩：https://doog87654321-eng.github.io/brainrot-bay-cn/**

Roblox 游戏《Brainrot Bay》的中文单机网页体验版（非参赛作品，仅供个人试玩）。

## 玩法

- **购买：**点击传送带上的角色，钱够就买进自己的基地（红色，左下角）。角色走出传送带就没了。
- **赚钱：**每个角色每秒按标注的 $/s 发钱，稀有度越高越能赚。
- **变异：**出生时可能带变异——黄金 ×2、钻石 ×5、彩虹 ×10，价格和收入都翻倍。
- **偷取：**点击邻居基地里的角色可以偷走，偷一次要等 30 秒冷却。邻居也会偷你的。
- **锁定基地：**$500 锁 60 秒，谁也偷不走你的角色。
- **转生：**攒够 $25,000（之后每次 ×6）可以转生：清空基地和现金，收入永久 ×2，可叠加。
- **海啸：**每 3 分钟来一次，提前 15 秒警告。警告时赶紧回自己的基地，被冲到要丢 10% 现金，传送带也会被洗空。
- **移动：**点击地面走过去，也可以用 WASD / 方向键走路。

## 角色

12 位原创角色，从面条怪（$2/s）到算法（$1,200/s），稀有度：普通 → 稀有 → 史诗 → 传说 → 神话 → 脑腐神 → 秘密。

## 技术

纯静态网页（HTML + CSS + Canvas JS），无构建步骤、零网络请求。进度自动保存在本机浏览器（localStorage）。

数值与机制照抄 Roblox 原版设计（`BrainrotCatalog.luau` 与 `GameConfig.luau`），单人版加了 3 个 AI 邻居（阿强、小美、大壮）共用一条传送带。
